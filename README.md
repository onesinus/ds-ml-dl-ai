The repository contains Jupyter notebooks, datasets, Python examples, trained models, visualization results, and small deployment projects.

Learning by building — from statistics and classical ML to deep learning and model deployment.

🛠️ Installation
Clone the repository:

git clone https://github.com/onesinus/ds-ml-dl-ai.git
cd ds-ml-dl-ai

Create a virtual environment:

python -m venv .venv

Activate it:

Linux / macOS
source .venv/bin/activate

Windows
.venv\Scripts\activate

Install the main dependencies:

pip install -r requirements.txt

📓 Running Jupyter Notebooks
Install Jupyter if necessary:

pip install jupyter

Start Jupyter:

jupyter notebook

or:

jupyter lab

Then choose any notebook from the sections above.

🚀 Running the FastAPI Example
cd fastapi-iris-model
docker compose up --build

API documentation:

http://localhost:8000/docs

📊 Running Streamlit
From the repository root:

streamlit run streamlit-learn.py
