Eksperimen & Evaluasi

1. Arsitektur:
Beberapa arsitektur dicoba: 1 LSTM (100), 2 LSTM (100,100), dan LSTM dengan dropout. Hasil terbaik diperoleh pada 2 LSTM tanpa dropout karena stabil dan tidak overfitting.

2. Akurasi:

  • Top-5: 76.3%
  • Top-10: 89.2%
  • Top-20: 96.4%
  • Top-100: 100%
  • Perplexity: ~2.3

3. Rekonstruksi Data:
Model tidak menyimpan data secara eksplisit, tetapi dapat meniru pola urutan. Risiko privasi muncul jika data latih bersifat sensitif.

Diskusi

Model LSTM cukup efektif mempelajari urutan kata meski data terbatas. Dengan dua layer LSTM dan optimisasi Adam, model menghasilkan prediksi yang cukup akurat. Akurasi top-k meningkat signifikan di k=5 dan ke atas, menunjukkan bahwa meskipun prediksi pertama tidak selalu tepat, kata yang benar tetap sering muncul di top list. Perplexity rendah mendukung kualitas prediksi model. Visualisasi grafik membantu dalam memahami distribusi probabilitas. UX juga ditingkatkan dengan adanya loading screen dan antarmuka interaktif berbasis tombol. Pelatihan model di sisi klien memberi keleluasaan namun butuh optimisasi lebih lanjut. Secara keseluruhan, proyek ini menunjukkan potensi NLP di browser dengan TF.js.

Dokumentasi

1. Teknis

  • TensorFlow.js – untuk membuat, melatih, dan menjalankan model LSTM di browser.
  • Plotly.js – untuk membuat grafik batang top-5 prediksi kata.
  • Material Design Style – digunakan untuk membuat UI yang jelas dan responsif.

2. Konten

  • Model dibangun dengan input 3 kata dan target 1 kata berikutnya.
  • Prediksi dilakukan dengan softmax pada layer output, dan top-k ditampilkan.
  • Fitur tombol interaktif dibuat untuk eksperimen manual dan otomatis.
  • Evaluasi dilakukan dengan menghitung akurasi top-k dan perplexity.
  • Referensi utama dari TensorFlow.js dan panduan Material Design.
